# Data Folder

The EduTrack project uses an instructor-supplied Excel workbook with five main tables: departments, instructors, students, courses, and enrollments.

The project brief says not to load the workbook's descriptive README sheet as a data table.

**Before adding data here:** confirm that the course rules and data ownership allow public sharing. Do not commit restricted, confidential, personal, or instructor-provided source data to a public repository without permission.

For now, this folder documents the source structure rather than containing the workbook itself.
