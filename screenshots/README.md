# Screenshot Checklist

Add screenshots only when they are ready and permitted for public sharing. Remove or obscure any private or sensitive information.

Suggested evidence:
- Get Data / Excel workbook selection.
- Transform Data selection.
- Power Query Editor.
- Data profiling and cleaning.
- Close & Apply.
- Model view and relationships.
- Edit Relationship dialog.
- Each selected report page.
- Final dashboard overview.

Use clear names such as `01-get-data.png`, `02-power-query.png`, `03-model-view.png`, and `04-q1-overview.png`.

Do not add screenshots that reveal credentials, personal student details, or restricted source data.
